Cuban modern · TriciGo home

Tocá el 🌙 en la top bar para alternar entre light y dark mode.

Decisiones clave

  • Paleta: naranja quemado (#FF4D00) + ámbar cálido (#FFB547) + azul ceniza (#6B7F8F). Background crema #FFFBF5 en light, navy oscuro #0A0E1A en dark.
  • Tipografías: Bricolage Grotesque (display + serivos), Instrument Serif itálica (títulos emocionales), Inter (body), JetBrains Mono (labels + números).
  • Silueta del Malecón como divider line-art (mirá entre "Recientes" y "Servicios") — tiene el Faro del Morro con luz naranja + olas sutiles debajo.
  • Inicio: saldo → pregunta "¿A dónde vamos hoy?" en serif itálica → input grande → recientes → servicios (4 tipos) → promo.

Respuestas integradas

  1. Balance siempre visible ✓
  2. Recientes inline ✓
  3. Logo wordmark TriciGo compacto en top bar ✓
  4. Silueta del Malecón como divider ✓ (Capitolio se sentía turístico)
  5. Light mode default + toggle dark ✓

Qué decidir vos

  • ¿El Malecón te cierra como elemento cubano o preferís probar el Capitolio?
  • ¿La promo es demasiado presente / muy poco? Tamaño y color se ajustan fácil.
  • ¿Iconos de servicios están bien? Si tenés SVG custom de tu diseñador, los reemplazamos.
  • ¿Querés sacar el precio "desde X CUP" en las cards de servicio para mantenerlas más limpias?
